# 截图目录

把应用截图放在这里，然后在项目根目录的 `README.md` 中引用它们，例如：

```markdown
| 首页 | 预设模板 |
|---|---|
| ![首页](docs/screenshots/home.jpg) | ![预设模板](docs/screenshots/presets.jpg) |

| 编辑面板 | 双语视频效果 |
|---|---|
| ![编辑面板](docs/screenshots/editor.jpg) | ![双语视频效果](docs/screenshots/overlay-bilingual.jpg) |
```

## 当前已提供的截图

| 文件 | 内容 |
|---|---|
| `home.jpg` | 首页：总开关、遮挡块列表、状态提示条 |
| `presets.jpg` | 预设模板：一键套用常见遮挡位置 |
| `editor.jpg` | 编辑面板：样式、颜色、透明度、圆角 |
| `overlay-bilingual.jpg` | 双语视频场景：盖住一种语言字幕，只留想看的那一行 |

## 拍摄提示

- 用手机自带的截图功能，无需额外工具。
- 截图前先关掉通知栏里的私人信息，避免泄露隐私。
- 如需强调夜间使用场景，可在深色模式下截取。
