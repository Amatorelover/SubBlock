# 截图目录

把应用截图放在这里，然后在项目根目录的 `README.md` 中引用它们，例如：

```markdown
| 首页 | 编辑面板 | 关于 |
|---|---|---|
| ![首页](docs/screenshots/home.png) | ![编辑面板](docs/screenshots/editor.png) | ![关于](docs/screenshots/about.png) |
```

## 建议拍摄的几张

1. **首页** —— 总开关、遮挡块列表、状态提示条
2. **编辑面板** —— 实时预览 + 颜色 / 透明度调节
3. **模板面板** —— 预设模板列表
4. **实际效果** —— 视频画面上遮挡字幕的前后对比（最有说服力）

## 拍摄提示

- 用手机自带的截图功能，无需额外工具
- 建议同时保留深色与浅色模式各一张
- 截图前先关掉通知栏里的私人信息，避免泄露隐私
